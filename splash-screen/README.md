# تخصيص شاشة الافتتاحية

يمكن تعديل شاشة الافتتاحية بعد إنشاء البرنامج التنفيذي، دون تعديل الشيفرة أو إعادة بناء البرنامج:

1. أنشئ مجلدًا باسم `splash-screen` بجانب ملف البرنامج التنفيذي إذا لم يكن موجودًا.
2. عدّل `config.json` لتغيير اسم المؤسسة والنص التعريفي واسم المطوّر أو الفريق ورقم الإصدار.
3. ضع شعار المؤسسة في المجلد، ثم اكتب اسم ملفه في `logo_file` (الافتراضي `logo.png`).
4. أغلق البرنامج وافتحه مجددًا لتظهر التعديلات.

تُقرأ الملفات من هذا المجلد في كل مرة تُفتح فيها الصفحة الافتتاحية. عند تشغيل نسخة المصدر
يُستخدم مجلد `splash-screen` الموجود في جذر المشروع. عند تشغيل نسخة مجمّعة تُستخدم نسخة
المجلد الموجودة بجانب الملف التنفيذي.
