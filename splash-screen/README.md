# إعداد شاشة الافتتاحية للإصدار

تُحدد بيانات شاشة الافتتاحية قبل بناء الإصدار، وتكون موحدة لجميع من يثبتونه. لا يستطيع المستخدم العادي تعديلها بعد التثبيت؛ تغييرها يتطلب تعديل ملفات المصدر وإصدار مثبت جديد.

1. قبل البناء، عدّل `config.json` لتحديد اسم المؤسسة والنص التعريفي واسم المطوّر أو الفريق ورقم الإصدار. يظهر `institution_name` أيضًا أسفل عنوان البرنامج في الشريط الجانبي.
2. ضع ملف الشعار في هذا المجلد واكتب اسمه في `logo_file` (الافتراضي `logo.png`).
3. ابنِ المثبت بواسطة `windows/build_windows.ps1`. يضم الإصدار الإعدادات والشعار داخل مجلد التطبيق المحمي، وتحتاج التغييرات اللاحقة إلى بناء مثبت جديد.

عند تشغيل نسخة المصدر يُستخدم مجلد `splash-screen` الموجود في جذر المشروع. وعند تشغيل النسخة المثبّتة تُقرأ الملفات المشحونة مع الإصدار، ولا تُحفظ في قاعدة بيانات المستخدم أو مجلد بياناته.
