أنواع العتاد

عرّف المستويات الأربعة التي تعتمدها مؤسستك: الفئة → النوع → العلامة → الطراز.

رقم التسجيل ورقم الهيكل (VIN) يخصان العتاد الفعلي ويُسجلان لاحقًا، أما ID النظام فينشئه النظام تلقائيًا.

1الفئة

المستوى الأعلى الذي تختاره مؤسستك.

مثال: المركبات، معدات الأشغال، معدات الدعم.

2نوع العتاد

نوع العتاد داخل الفئة، مثل مركبات خفيفة.

وحدة العداد بيانات تشغيلية لازمة للصيانة، وليست مستوى تصنيف إضافيًا.

{% for t in types %}
{{ t.name }}
{{ t.category.name if t.category else "بدون فئة" }} · {{ "كيلومترات" if t.measurement_unit == "km" else "ساعات تشغيل" }}
{% else %}

لم تتم إضافة أي نوع بعد.

{% endfor %}

3العلامة

علامة/صانع العتاد، ويمكن استخدامها مع عدة طُرز.

مثال: Toyota، Mercedes-Benz، Caterpillar.

{% for b in brands %}
{{ b.name }}
{% else %}

لم تتم إضافة أي علامة بعد.

{% endfor %}

4الطراز

الطراز الذي ستُبنى عليه قواعد الصيانة والتعداد النظري.

التعداد النظري يُستخدم في الحالة العددية والاحتياج، وليس هو عدد الأعطال.

{{ m.name }}

إعداد الإطارات
{% else %}

لم تتم إضافة أي طراز بعد.

وعند تسجيل العتاد الفعلي من هذا الطراز: رقم التسجيل ورقم الهيكل (VIN) يميزان العتاد، أما ID النظام فيُنشئه النظام تلقائيًا ولا يدخله المستخدم.
