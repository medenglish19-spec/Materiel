# استيراد الخصائص الفنية محليًا
يدعم PDF النصي وDOCX وXLSX. الاستيراد لا ينفذ اتصالات شبكة ولا ينزّل نماذج. PDF الممسوح ضوئيًا يحتاج OCR مثبتًا مسبقًا؛ النسخة الحالية لا تنزّل أي محرك OCR تلقائيًا. المطابقة لا تنشئ تعريفات جديدة، والحفظ يقتصر على العناصر التي وافق عليها المستخدم ويجري داخل معاملة واحدة. حد الملف 15 MiB.
