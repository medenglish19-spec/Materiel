# Document Import (Offline)

وحدة استيراد الخصائص التقنية من مستندات (PDF/DOCX/XLSX) محليًا بالكامل دون إنترنت.
يدعم Docling + pypdf + openpyxl + python-docx مع fallback لـ PaddleOCR للـPDF الممسوح ضوئيًا.

يعرض المرشحين للمراجعة قبل التطبيق. لا يُنشئ تعريفات خصائص تلقائياً. يطبق فقط المعتمد منها والموجودة مسبقًا في مكتبة التعريفات.
